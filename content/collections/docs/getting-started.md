Lettern runs anywhere PHP 8.4 runs — from shared hosting with only FTP access to containers. These guides take you from download to a published site.

- [Requirements](/getting-started/requirements) — what your server needs.
- [Installation](/getting-started/installation) — upload a small zip, or use Composer.
- [Quick start](/getting-started/quick-start) — collections, the block workspace, the design system and publishing.
- [Project structure](/getting-started/project-structure) — Lettern's code versus your site's files.
- [Configuration](/getting-started/configuration) — `.env`, YAML config and settings.
- [Upgrading](/getting-started/upgrading) — updating Lettern and its plugins safely.
