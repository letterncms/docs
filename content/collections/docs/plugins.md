The admin's screens are modules inside `letterncms/cms`; the builder, the static site, SEO, media, forms, email, MCP and the assistant are plugins, each a Composer package and a repository of its own. Both are the same kind of package, none uses a private API, and each can be switched off or replaced. That is the best documentation there is — read their code next to these pages.

- [Modules](/plugins/modules) — what the admin is made of, switching parts off, their settings and what each costs

- [How plugins work](/plugins/how-plugins-work) — packages, providers, lifecycle, blocks, data sources, collections
- [Your first plugin](/plugins/your-first-plugin) — a complete, working example
- [Hooks](/plugins/hooks) — every action and filter
- [Admin extensions](/plugins/admin-extensions) — screens, panels, block workspaces, fields, commands
